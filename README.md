# DISTANCE-BETWEEN-TWO-POINTS

## AIM:
To write a python program to find the distance two 2 points
## ALGORITHM:

Step 1: Start the program.

Step 2: Assign the coordinates of the two points:

Step 3: Substitute the values in the distance formula:

Step 4: Calculate the distance using the formula.

Step 5: Display the distance up to 2 decimal places and end the program.

### PROGRAM:

```
import math

x1, y1 = 4, 2
x2, y2 = 10, 6

d = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)

print("{:.2f}".format(d))

```
